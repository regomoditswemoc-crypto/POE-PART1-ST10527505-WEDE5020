This is a website I built for my WEDE5020 assignment. It's for a small bakery called Sunrise Bakery that's based in Roodepoort.

What the site does:
It's a simple, 5-page website. People can use it to see what bread and cakes the bakery sells. There is also a form where customers can ask about custom cakes for birthdays or weddings. I also added a page with the shop's address, contact number, and opening times.

What I used to make it:
For this project, I only used HTML, CSS, and a little bit of JavaScript. All the coding is done in VS Code.

What it looks like:
I went with a soft pink and cream color theme because I wanted it to feel warm and cozy, like a real bakery. I added a couple of pictures of cakes that I found online to make the homepage look more inviting.

How to open it:
If you want to view the website, just download the files, open the folder, and double-click the file named index.html. It will open up in your browser.
